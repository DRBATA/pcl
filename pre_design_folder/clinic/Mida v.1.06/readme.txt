******************
Theme installation
******************

Standard Theme Installation:
1) Use mida.zip file to upload new theme in Appearance -> Themes -> Add new.
2) Install all required plugins and activate them.
3) You can import the demo content for a quick site setup.
   Tools -> Demo Content Install. Will install all demo content for the site.

Notice: if you want to use a child-theme, you can also upload the file mida-child.zip in addition to the main Mida theme.

Please visit https://docs.duckthemes.com/faq/installation/ for detailed information.
